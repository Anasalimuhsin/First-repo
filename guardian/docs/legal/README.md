## ما يجب استكماله قبل النشر

- [ ] استبدال كل ما بين أقواس مربعة: `[اسم الشركة]`، `[العنوان]`، `[بريد الخصوصية]`، `[الدولة/القانون الحاكم]`، `[منطقة الاستضافة]`، `[مسؤول حماية البيانات]`.
- [ ] تحديد الدول المستهدفة عند الإطلاق، ومراجعة كل مسودة مقابل قانون كل دولة (مثلاً: COPPA في الولايات المتحدة، نظام حماية البيانات الشخصية في السعودية، المرسوم بقانون 45/2021 في الإمارات، اللائحة الأوروبية GDPR).
- [ ] اعتماد طريقة التحقق من هوية ولي الأمر للإنتاج (الكود يدعم فحص بطاقة عبر Stripe، و`dev_attestation` مرفوضة في الإنتاج).
- [ ] توقيع اتفاقيات معالجة البيانات مع كل معالج في `subprocessors.md`.
- [ ] ترجمة إنجليزية معتمدة (مطلوبة لمتاجر التطبيقات وللسوق الأمريكية).
- [ ] رفع `PRIVACY_POLICY_VERSION` (الخادم) و`NEXT_PUBLIC_POLICY_VERSION` (الويب) عند أي تعديل جوهري؛ سيُطلب من الوالدين الموافقة من جديد.
- [ ] إعادة مراجعة كل المسودات عند بناء تطبيق الطفل، لأن الأذونات وتدفقات البيانات على جهازه لم تُحدَّد نهائياً بعد.

## مبدأ الاتساق

كل ادعاء في هذه الوثائق يجب أن يطابق الكود. عند تغيير سلوك متعلق بالبيانات (مدة احتفاظ، معالج جديد، نوع بيانات جديد)، حدّث الوثيقة في نفس طلب الدمج. المراجع في الكود:

| الادعاء | مكانه في الكود |
|---|---|
| مدد الاحتفاظ (90 يوماً للتنبيهات، 30 للمواقع، سنة لسجل التدقيق) | `backend/db/migrations/001_initial.sql`، `backend/src/jobs/retention.js` |
| عدم حفظ نص الرسائل كاملاً (مقتطف 280 حرفاً فقط) | `backend/src/services/alerts.js` (`EXCERPT_LENGTH`) |
| التشفير AES-256-GCM للمقتطفات والرموز | `backend/src/lib/fieldCrypto.js` |
| لا يُرسل لمزوّد الذكاء الاصطناعي إلا بموافقة `llm_analysis`، ودون اسم أو معرّف | `backend/src/services/alerts.js`، `backend/src/analyzer/llmClassifier.js` |
| الصور لا تُرفع للخادم | `backend/src/routes/device.js` (`/image-signals` يقبل تصنيفات فقط) |
| سحب الموافقة يوقف الجمع فوراً | `backend/src/lib/auth.js` (`requireScope`) |
| التصدير والحذف | `backend/src/routes/privacy.js` |
| تسجيل كل اطلاع على مقتطف أو موقع | `backend/src/routes/alerts.js` (`audit`) |
