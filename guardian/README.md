# Guardian — تطبيق السلامة الرقمية للأطفال

منصة لحماية الأطفال رقمياً على غرار Bark: تحلّل المحتوى بالذكاء الاصطناعي لاكتشاف التنمّر وإيذاء النفس والاستدراج والعنف، وتنظّم وقت الشاشة وتصفية الويب، وتتابع الموقع مع تنبيهات الوصول والمغادرة.

> **مبدأ تصميم أساسي:** التطبيق **ظاهر للطفل** ويعمل بموافقة وليّ الأمر الموثّقة. الطفل يعرف أنه موجود، ولا يرى الوالد الرسائل كلها، بل **التنبيهات فقط** مع مقتطف قصير من الرسالة المقلقة. هذا ما يميّز تطبيق حماية عن تطبيقات التجسس، وهو شرط لقبول التطبيق في متجري Apple وGoogle.

## البنية العامة

```
 ┌──────────────── جهاز الطفل (React Native) ────────────────┐
 │  جمع المحتوى المسموح به  ·  الموقع  ·  تطبيق سياسات الشاشة  │
 └───────────────┬───────────────────────────▲───────────────┘
                 │ HTTPS (TLS 1.3) + توكن الجهاز   │ GET /policy
                 ▼                            │
 ┌──────────────────────── Guardian API (Express) ────────────────────────┐
 │  1) محرك القواعد (محلي، كل رسالة)                                       │
 │  2) Claude (فقط للرسائل المشبوهة + بموافقة llm_analysis)                │
 │  3) أرضية أمان: إشارات إيذاء النفس الحرجة لا يمكن للنموذج إسكاتها       │
 │  ➜ يُحفَظ التنبيه فقط (مقتطف مشفّر AES-256-GCM)، والنص الكامل يُتلَف     │
 └───────┬───────────────────────────────┬─────────────────────────────────┘
         ▼                               ▼
   PostgreSQL                      Firebase Cloud Messaging
   (تنبيهات، سياسات،               (إشعار فوري للوالدين لا يحتوي
    مواقع، سجل تدقيق)                على نص الرسالة)
         ▲
         │  HTTPS + جلسة الوالد
 ┌───────┴──────────────────────────────┐
 │ لوحة الوالدين (Next.js) + تطبيق الوالد │
 └──────────────────────────────────────┘
```

**التقنيات المختارة:** React Native (تطبيقا الطفل والوالد بقاعدة كود واحدة) · Next.js (لوحة الويب) · Node.js/Express 5 (الخادم) · PostgreSQL (البيانات) · Firebase Cloud Messaging (الإشعارات الفورية) · Claude API (التصنيف السياقي).

> لماذا FCM وليس Firebase Realtime DB للتنبيهات؟ التنبيهات بيانات حساسة؛ نبقيها في PostgreSQL المشفّر ونستخدم Firebase **فقط** لإيصال الإشعار (بدون محتوى)، فيفتح الوالد التطبيق ويجلب التفاصيل بعد التوثيق.

## محرك تحليل النصوص

يعمل على مرحلتين:

1. **محرك القواعد** (`ruleEngine.js`) — سريع ومجاني ويعمل على كل رسالة:
   - يوحّد النص أولاً: يحذف التشكيل والتطويل، ويوحّد (أ/إ/آ → ا) و(ة → ه) و(ى → ي)، ويختصر الحروف المكرّرة (`مووووت` → `موت`)، ويفكّ leetspeak (`k1ll` → `kill`).
   - يطابق العبارات مع حدود كلمات حقيقية تدعم السوابق العربية (و، ف، ب، ل، ك، ال) فتُكتشف "بالانتحار" دون أن تُطابَق "سكينة" مع "سكين".
   - يجمع النقاط لكل فئة؛ عدة إشارات ضعيفة معاً قد ترفع التنبيه.
2. **مصنّف Claude** (`llmClassifier.js`) — اختياري، يُستدعى فقط للرسائل التي رصدتها القواعد، ويفهم السياق: المزاح بين الأصدقاء، كلمات الأغاني، العامية، والعربيزي. يعيد JSON منظّماً (فئة، خطورة، ثقة، سطر تفسير للوالد).

**أرضية الأمان:** إذا وجدت القواعد إشارة حرجة أو إشارة إيذاء نفس، يصدر التنبيه حتى لو قال النموذج إنها غير مقلقة. تفويت تنبيه انتحار أخطر بكثير من تنبيه خاطئ. وإذا تعذّر الوصول إلى النموذج، تقرّر القواعد وحدها.

مثال الاستخدام:

```js
import { analyzeMessage } from './src/analyzer/index.js';
import { classifyWithLLM } from './src/analyzer/llmClassifier.js';

const result = await analyzeMessage(
  { text: 'محد يحبك روح موت', source: 'instagram', direction: 'incoming' },
  { classify: classifyWithLLM }, // أو null للقواعد فقط
);
// → { alert: true, category: 'bullying', severity: 'high', detector: 'rules+llm',
//     labelAr: 'تنمّر إلكتروني', parentGuidanceAr: 'اطمئن على شعور طفلك أولاً…', … }
```

## التشغيل محلياً

المتطلبات: Node.js 20+ وPostgreSQL 14+.

```bash
cd guardian/backend
npm install
cp .env.example .env            # ثم ضع مفتاحاً: openssl rand -base64 32

createdb guardian
export $(grep -v '^#' .env | xargs)
npm run db:schema               # إنشاء الجداول
npm run seed                    # عائلة تجريبية + طباعة توكن الوالد والجهاز
npm start                       # http://localhost:3000

npm test                        # الاختبارات (لا تحتاج قاعدة بيانات)
npm run analyze -- "انت فاشل ومحد يحبك"          # تجربة المحلّل
npm run analyze -- --llm "بقتلك اذا ما جيت الجيم 😂"  # مع Claude (يتطلب ANTHROPIC_API_KEY)
```

## واجهة البرمجة (API)

| الطريقة | المسار | من يستدعيه | الوصف |
|---|---|---|---|
| POST | `/v1/device/messages` | جهاز الطفل | دفعة رسائل للتحليل؛ يُحفظ التنبيه فقط ويُتلف النص |
| POST | `/v1/device/locations` | جهاز الطفل | نقاط GPS؛ يحسب الدخول/الخروج من السياجات الجغرافية |
| GET | `/v1/device/policy` | جهاز الطفل | جداول وقت الشاشة، الحدود اليومية، قواعد الحظر |
| GET | `/v1/children` | الوالد | الأطفال مع عدد التنبيهات الجديدة |
| GET | `/v1/children/:id/alerts` | الوالد | خلاصة التنبيهات (بدون مقتطفات) |
| GET | `/v1/alerts/:id` | الوالد | التنبيه كاملاً مع المقتطف المفكوك — **يُسجَّل في سجل التدقيق** |
| PATCH | `/v1/alerts/:id` | الوالد | تغيير الحالة: viewed / resolved / dismissed |
| GET | `/v1/children/:id/location` | الوالد | آخر موقع وأحداث الوصول/المغادرة — **يُسجَّل** |

كل نقطة نهاية للجهاز مشروطة بنطاق موافقة (`content_monitoring`، `location`، `screen_time`)، وتحليل Claude مشروط بنطاق مستقل `llm_analysis` لأنه إفصاح لطرف ثالث.
